# Inventory Management React Frontend

This React app provides a user interface for logging in and searching server inventory data.

- `App.js`: Main component managing authentication status, search results, and rendering components.
- `Login.js`: Handles user login form, communicates with backend, and retrieves JWT token.
- `SearchBar.js`: Provides search input to send queries to backend.
- `ServerList.js`: Displays list of servers matching search query.

Uses JWT token from login to authenticate API requests.
